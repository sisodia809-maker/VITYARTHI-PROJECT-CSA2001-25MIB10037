# 8-Puzzle Solver Using BFS

This project implements an **8-Puzzle Solver using Breadth First Search (BFS)** as part of the *Fundamentals in AI and ML (CSA2001)* course.
The 8-Puzzle is a 3×3 sliding-tile puzzle containing eight numbered tiles and one empty space. The objective is to transform an initial configuration into the goal state by moving tiles into the empty space.
The project uses **BFS to explore possible puzzle states level by level** and find the shortest sequence of moves leading to the goal state. Puzzle configurations are represented as strings, while a queue is used to manage states and a visited set prevents repeated states.
 Features
* Solves the 8-Puzzle using BFS.
* Finds the shortest solution path.
* Displays intermediate board states.
* Uses simple and easy-to-understand Python code.
* Works with solvable puzzle configurations.
Technologies
* Python
* Breadth First Search (BFS)
* Queues, lists, strings, and sets
This project helped develop an understanding of **AI search algorithms, state-space representation, Python programming, and logical problem-solving**. Future improvements could include implementing A*, adding a GUI, checking puzzle solvability, and adding animations.
